# Kirby & The Amazing Mirror (USA) Randomizer
This is a randomizer for the American release of Kirby &amp; The Amazing Mirror. It currently allows for the randomization of rooms only.
This was principally made to be combined with the archipelago randomizer.

# Setup
- Download and extract the zip of the repo
- Start the amrRandomizer.py
- Select the ROM (if you want to combine with the archiepalgo, apply the AP patch before and select the patched ROM)
- Select your options and generate the ROM !
